BROKER AMLAK — راهنمای ساختار مخزن و یکپارچه‌سازی
====================================================

این نسخه، صفحه عمومی جدید را با پنل مدیریت قبلی یکپارچه می‌کند.
ظاهر صفحه عمومی جدید حفظ شده و موتور انتشار خودکار پنل به همان قالب جدید متصل است.

ساختار فایل‌ها
--------------
index.html
  صفحه عمومی سایت. شامل ظاهر جدید، تنظیمات پایه SEO، داده‌های فایل‌های قابل نمایش
  و داده ساختاریافته RealEstateAgent است.

app/index.html
  پنل مدیریت قبلی. امکانات مدیریت فایل‌ها، مشتریان، بازدیدها، معاملات،
  ذخیره محلی، پشتیبان‌گیری/بازیابی، پیش‌نمایش و انتشار در GitHub در همین فایل باقی است.
  بخش buildShowcase در این فایل به قالب عمومی جدید وصل شده است؛ بنابراین انتشار خودکار
  پنل دیگر نباید قالب قدیمی را جایگزین ظاهر جدید کند.

app/manifest.webmanifest
  تنظیمات نصب پنل به‌صورت وب‌اپ.

app/sw.js
  Service Worker پنل. شناسه کش به ba-v2 تغییر کرده تا نسخه جدید پنل دریافت شود.

app/icon-192.png و app/icon-512.png
  آیکون‌های نصب پنل.

CNAME
  دامنه سفارشی broker-amlak.ir.

robots.txt
  اجازه خزش صفحات عمومی و جلوگیری از خزش مسیر پنل /app/.

sitemap.xml
  نقشه فعلی سایت؛ فعلاً فقط صفحه اصلی را معرفی می‌کند.

README.md
  همین راهنما.

نحوه بارگذاری در GitHub
-----------------------
1) از مخزن فعلی یک نسخه پشتیبان بگیر.
2) محتویات این بسته را در ریشه همان مخزن بارگذاری کن؛ پوشه broker-site-main را
   به‌عنوان یک پوشه تو در تو در مخزن ایجاد نکن.
3) فایل‌ها را با حفظ مسیرها جایگزین/اضافه کن:
   - index.html در ریشه مخزن
   - robots.txt و sitemap.xml در ریشه مخزن
   - app/index.html و app/sw.js در پوشه app
   - فایل‌های manifest و آیکون‌های app بدون تغییر مسیر باقی بمانند.
4) CNAME را حفظ کن.
5) پس از انتشار، این آدرس‌ها را بررسی کن:
   https://broker-amlak.ir/
   https://broker-amlak.ir/robots.txt
   https://broker-amlak.ir/sitemap.xml
   https://broker-amlak.ir/app/

نکات مهم سازگاری
----------------
- پنل قبلی و کلیدهای ذخیره‌سازی مرورگر آن تغییر داده نشده‌اند.
- ساختار داده‌های فایل‌ها و پروفایل حفظ شده است؛ خروجی ویترین از فایل‌های فعال
  و فایل‌هایی که برای انتشار عمومی غیرفعال نشده‌اند ساخته می‌شود.
- شماره تماس و لینک‌های بله/اینستاگرام صفحه عمومی از اطلاعات پروفایل پنل خوانده می‌شوند.
- قالب جدید در موتور انتشار خودکار پنل تعبیه شده است.
- اگر اتصال GitHub در پنل فعال است، مخزن و شاخه فعلی را تغییر نده.
- بعد از بارگذاری، یک فایل آزمایشی را در پنل ویرایش کن و انتشار را بررسی کن؛
  سپس مطمئن شو همان ظاهر جدید و اطلاعات درست در صفحه اصلی دیده می‌شود.

محدودیت‌ها و مراحل بعدی
----------------------
- این بسته زیرساخت اولیه SEO است و رتبه گوگل را تضمین نمی‌کند.
- sitemap فعلاً فقط صفحه اصلی را دارد؛ صفحات محله، مقاله و جزئیات ملک بعداً
  پس از ساخته‌شدن واقعی آن صفحات به نقشه اضافه می‌شوند.
- Google Search Console هنوز باید به‌صورت جداگانه تأیید و sitemap آنجا ثبت شود.
- تصویر اجتماعی اختصاصی (og:image) فعلاً عمداً تنظیم نشده تا تصویر واقعی آماده شود.
- قبل از انتشار عمومی، پنل و مسیر انتشار GitHub را در محیط واقعی آزمایش کن.


به‌روزرسانی بخش «آشنایی بیشتر با بروکر»
--------------------------------------
متن پنجره آشنایی بیشتر با بروکر با متن معرفی جدید سایت هماهنگ شد.
مقدار پیش‌فرض پنل نیز به همین متن تغییر کرده است؛ متن اختصاصی دیگری که کاربر در پنل ذخیره کرده باشد، حفظ می‌شود.


مدیریت تصاویر فایل‌های ملکی (بدون تغییر نام عکس)
-----------------------------------------------
عکس‌ها را با نام اصلی خود داخل پوشه images قرار دهید و فقط در فایل
images/manifest.json شناسه فایل را به نام عکس وصل کنید. نمونه:

{
  "f1730000000": "living-room-final.webp",
  "f1730000001": "IMG_2048.jpg"
}

کلید هر سطر، شناسه فایل در پنل است و مقدار آن نام/مسیر نسبی عکس داخل پوشه images است.
نام عکس لازم نیست تغییر کند. اگر برای فایلی تصویری در manifest ثبت نشده باشد،
تصویر جایگزین فعلی سایت نمایش داده می‌شود. این سازوکار فقط در سایت عمومی است و
عکس‌ها یا مسیرشان در دیتابیس و اطلاعات ذخیره‌شده پنل ثبت نمی‌شوند.
